# Scarbopoly
UTSC CSCB07 final project.

Scarbopoly is a Monopoly-style board game that supports up to six players. Players take turns rolling dice, moving around the board, and performing actions based on the squares they land on. Throughout the game, players can purchase and manage properties (buildings), collect tuition (rent) from other players, and work toward acquiring complete sets of properties known as monopolies. Owning a monopoly increases the tuition charged to other players, allowing players to accumulate wealth and gain an advantage. The game continues until all but one player has declared bankruptcy, with the last remaining player being the winner. 
 
The goal of this project is to design a fully functional implementation of Scarbopoly using object-oriented programming principles. Our approach involves dividing the game into separate classes responsible for managing players, the board, properties, and game mechanics. We designed the overall structure using a UML class diagram before implementing the core functionality. Development will be split as evenly as possible between all partners.
